### Exercícios

**1)** Usando HTML, CSS e JS, escreva um algoritmo que leia o raio de um círculo. O algoritmo deve calcular a área do círculo.
Crie os arquivos `pratica03exercicio04.html`, `pratica03exercicio04.css` e `pratica03exercicio04.js`.
*OBS:* área = π * (raio)²
*Usar:* `Math.PI`

**2)** Usando HTML, CSS e JS, escreva um algoritmo que leia o raio de uma esfera. O algoritmo deve calcular o volume da esfera. 
Crie os arquivos `pratica03exercicio05.html`, `pratica03exercicio05.css` e `pratica03exercicio05.js`.
*OBS:* volume = 4 / 3 * π * (raio)³
*Usar:* `Math.PI`

**3)** Usando HTML, CSS e JS, escreva um algoritmo para cálculo de juros compostos. O usuário deve informar o capital inicial, a taxa de juros e o prazo (tempo) de investimento. O algoritmo deve calcular o montante, considerando que a taxa e o prazo são relativos à mesma unidade de tempo. 
Crie os arquivos `pratica03exercicio06.html`, `pratica03exercicio06.css` e `pratica03exercicio06.js`.
*OBS:* M = C * (1 + i)^t
Em que M é o montante, C é o capital inicial, i é a taxa de juros e t é o tempo.
