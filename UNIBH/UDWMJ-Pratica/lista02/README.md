### Lista de Exercícios Práticos: HTML e CSS

Crie um novo repositório chamado: **lista-02-udwmj**

#### Exercício 1: Cartão de Visitas Digital
Crie uma página simples que funcione como um cartão de visitas pessoal.
- **HTML:** Utilize tags de cabeçalho (`<h1>`), parágrafo (`<p>`) para uma breve bio e uma lista (`<ul>` ou `<ol>`) com seus links sociais ou contatos.
- **CSS:** Altere a cor do fundo da página (`background-color`), a cor do texto e centralize os elementos na tela.

#### Exercício 2: Perfil de Personagem
Monte uma página sobre um personagem de filme, série ou jogo de que você gosta.
- **HTML:** Insira um título com o nome do personagem, uma imagem (`<img>`) dele e uma lista de suas principais características ou habilidades.
- **CSS:** Defina uma largura fixa para a imagem, adicione uma borda arredondada (`border-radius`) nela e mude a fonte do texto (`font-family`).

#### Exercício 3: Receita Simples
Crie a estrutura de uma receita culinária básica.
- **HTML:** Use um título para o nome do prato, uma lista não ordenada (`<ul>`) para os ingredientes e uma lista ordenada (`<ol>`) para o passo a passo do modo de preparo.
- **CSS:** Adicione um espaçamento interno (`padding`) na página e mude a cor do texto das listas para diferenciar dos títulos.

#### Exercício 4: Botão Estilizado
Desenvolva um botão interativo para uma página web.
- **HTML:** Insira um link (`<a>`) ou elemento de botão (`<button>`) com o texto "Clique Aqui" ou "Saiba Mais".
- **CSS:** Remova a sublinhado padrão (se for link), adicione cor de fundo, cor de texto, espaçamento interno (`padding`) e use o seletor `:hover` para mudar a cor do botão quando o mouse passar por cima.

#### Exercício 5: Bloco de Destaque (Card de Notícia)
Crie um pequeno quadro de notícia ou aviso.
- **HTML:** Agrupe um título, uma data/autor e um parágrafo dentro de uma tag `<div>`.
- **CSS:** Aplique na `<div>` uma cor de fundo diferente, uma borda fina, cantos arredondados (`border-radius`) e defina uma largura máxima (`max-width`).

#### Exercício 6: Tabela de Preços Simples
Monte uma tabela exibindo planos ou produtos fictícios.
- **HTML:** Utilize a tag `<table>` com linhas (`<tr>`) e células (`<td>` e `<th>`) para listar 3 produtos e seus respectivos preços.
- **CSS:** Adicione bordas às células da tabela, altere a cor de fundo do cabeçalho da tabela e defina um alinhamento de texto centralizado.

#### Exercício 7: Rodapé de Site (Footer)
Crie a seção inferior padrão de um site.
- **HTML:** Use a tag `<footer>` contendo um texto de direitos autorais (ex: "© 2026 - Todos os direitos reservados") e um link para contato.
- **CSS:** Fixe a cor de fundo do rodapé em um tom escuro com texto claro, ajuste o alinhamento para o centro e defina um espaçamento superior (`margin-top`).
